## 🛠 Common Git Commands

### Initialize a Repository

```bash
git init
```

### Check Status

```bash
git status
```

### Add Files

```bash
git add .
```

### Commit Changes

```bash
git commit -m "Initial commit"
```

### Create a Branch

```bash
git branch feature-branch
```

### Switch Branches

```bash
git checkout feature-branch
```

### Merge Branches

```bash
git merge feature-branch
```

### Push to GitHub

```bash
git push origin main
```
